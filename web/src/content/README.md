# content

## Overview

This directory holds the data of the ChainGauge site. A single store of `Chain` records in `chains.ts` feeds every view, and the framework definitions, the public changelog and the generated chain icons are kept beside it. Adding a chain is one new entry in the `CHAINS` array and needs no new plumbing, as the header of `types.ts` states.

## Interface

- `types.ts` exports the model types `Chain`, `Rating`, `Stat`, `Source`, `Exposure`, `Basis`, `Band`, `Category` and `Relevance`. It re-exports `Level` and `DimensionId` from `api/_lib/submission.ts` through the `@shared` alias.
- `chains.ts` exports `CHAINS` (54 entries when checked), `NOT_RATED` (networks deliberately left out, each with a reason and sources) and `FEED_META` (the `asAt` date and the chain count).
- `methodology.ts` exports `DIMENSIONS` (the seven factors in wedge order), `DIMENSION_BY_ID`, `LEVELS`, `LEVEL_BY_ID`, `BANDS` and `BAND_BY_ID`, with the `DimensionDef`, `LevelDef` and `BandDef` types.
- `changelog.ts` exports `CHANGELOG` (newest first), `UNDER_REVIEW`, `CHANGELOG_META` (the stated response target), `ACTION_LABEL` and the `ActionKind`, `ChangeEntry` and `ReviewItem` types.
- `chainIcons.ts` exports `CHAIN_ICON`, a map from chain id to inlined SVG markup. The file is generated by `../../../tools/gen-icons.mjs` and carries a do-not-edit header.

## Invariants

- `Chain.residual` is a required field because seven clear ratings do not mean the chain is safe, and the comment on `residual` in `types.ts` states that no chain may leave it empty. No test or script enforces that.
- A hard fact carries a real source URL. A rating or stat that is an assessed judgement carries no source and is labelled as such (header of `chains.ts`).
- The citation objects are defined in the `S` block of `chains.ts`, between the lines `const S = {` and `// Small builders`. `../../scripts/source-check.mjs` and `../../scripts/link-check.mjs` locate citations by those two markers and a regular expression, so the layout of that block must not change.
- A citation name that mentions a known organisation other than the host of its link must contain the word "via". A citation marked `kind: "primary"` must be on the host of the organisation it names (`source-check.mjs`).
- `Rating.basis` is set to `no-record` only where the level rests on a missing track record. Absence of evidence must not render as evidence of absence.
- `AS_AT` in `chains.ts` moves when every chain is re-examined, and `reviewed` on a chain records when that chain alone was last examined.
- The order of `DIMENSIONS` fixes the rosette wedge order, and `types.ts` states that the band is derived from the ratings and never stored.
- Each `CHANGELOG` entry records a `date`, a `kind`, a `title` and a `detail` (the reason), with optional `chains` and `prompted`. The views do not sort the list, so a new entry goes at the top.
- Copy in this directory is subject to `../../scripts/prose-check.mjs`.

## Side Effects

- None found in this directory. All files export constants and types only.

## Verification

- Run in `web/`: `npm run source:check` for citation attribution.
- Run in `web/`: `npm test` (the tests in `../lib` iterate over `CHAINS`).
- Run in `web/`: `npm run prose` for the copy check.
- Run in `web/`: `npm run link:check` to probe the cited URLs. It is not part of `npm run gates` because it needs the network.
